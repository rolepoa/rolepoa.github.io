Dados Locais de Exemplo

Usando curadoria local de exemplo. Cole o link da sua planilha pública do Google Sheets para sincronizar toda semana.

Colunas esperadas na aba/planilha (linha 1 = cabeçalho): id, title, category, neighborhood, dayLabel, dayKey (Qui, Sex, Sáb, Dom), priceLabel, isFree (true/false/sim/free), vibe, tags (separadas por ; ou |), image, url, mapsUrl, description. Dica: deixe a planilha pública como "Qualquer pessoa com o link pode ver" ou publique na web como CSV. Se falhar ou estiver offline, o site mantém os dados locais automaticamente.
